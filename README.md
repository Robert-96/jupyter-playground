# Jupyter Playground

Repository for experimenting with Jupyter notebooks, showcasing data analysis, visualization, and machine learning techniques.

## Setup

1. Clone the repository:

```bash
git clone https://github.com/Robert-96/jupyter-playground.git
cd jupyter-playground
```

2. Create a virtual environment and activate it:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

3. Install the required packages:

```bash
pip install -r requirements.txt
```

4. Start Jupyter Notebook:

```bash
jupyter notebook
```
